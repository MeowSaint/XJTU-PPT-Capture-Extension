# 3.1.2 整课 PDF 目录与工作台设计

## 目标与执行依据

用户先提出整课 PDF 内置目录与自有云 API 转录，随后明确要求先完成 PDF，同时改善操作入口与界面动效，并指定 Apple Design，参考 React Bits 和 Anime.js。本轮完成 PDF 与 UI；转录、音频提取、词库与云 API 接入暂缓。

以下是据现有源码和只读走查确定的执行选择，不记为用户逐项批准的视觉稿。直接执行用户已明确要求的工作，常规样式和实现选择由执行者承担；最终提供可操作界面、合成示例与验证记录。

## 现状与取舍

- 3.1.1 已有单课平级页码书签、分课 PDF ZIP，没有跨课次的一份 PDF。新增独立流式入口，复用图片和对象输出；旧导出字节不变。
- 当前是原生 JavaScript / MV3 / IndexedDB / OPFS。保留这些结构；不迁移 React，不新增运行时依赖或云服务。
- 保持 Chrome 114+、Node.js 20+；不改变 IndexedDB schema、使用约定、域名授权或真实任务的 busy/停止保护。
- 主要入口分散于窄侧栏、右上角、预览工具与图库。重排现有控件和提示，比另建组件体系更容易保持存储、恢复和授权逻辑。
- React Bits 参考列表反馈与方向指示；Anime.js 参考当前值读取和连续重定向。按下、面板、卡片、预览的离散反馈使用原生 CSS / WAAPI；裁剪拖动继续 1:1 跟随指针，不加插值。没有拖动释放动画时不自建弹簧物理引擎。

## 整课 PDF

新增 `writeCoursePDF(lessons, {title, layout = 'single', timestamps = false, readImage, write}) -> Promise<void>`。`lessons` 是有序 `{title: string, pages: PageMetadata[]}`，PDF 层不访问数据库。

- 内置三级目录：课程 → 第 N 课 · 日期/开始时间 → 第 N 页 · HH:MM:SS。目录文本用带 BOM 的 UTF-16BE hex string；中文、emoji、括号及反斜杠完整保留，孤立代理项替换为 U+FFFD，不引入字体文件。
- 整课合并始终生成完整目录，并设置 `/PageMode /UseOutlines` 请求阅读器显示；实际是否展开由阅读器决定。现有 `bookmarks` 选项继续只控制单课、所选及分课 ZIP 的平级页码书签。打印时间由 `timestamps` 独立控制，目录中的有效时间不受其影响。
- 课程标题缺失为“未命名课程”；课次标题使用稳定序号与已有日期/时间，缺字段显示“未知日期”“未知时间”，不补造上课时间。叶节点时间仅接受有限、非负 number，保留 0，向下取整，允许超过 99 小时。
- 每课从新物理页开始。讲义布局按课次独立两图分组：`[3,1]` 为 3 张 A4，上一课末尾的空下半区不放下一课。图片、连续编号与目录目的地共享 sheet/row 映射，叶页码以课内顺序计数。纸张页脚仍按物理页连续计数。
- 顺序保持课程原有日期、开始时间、created 排序；课内按保留的 page.order。空课次不生成目录目的地，未完成但有截图的课次可以导出，并明确提示。
- 新文件名“课程名-整课.pdf”，清理不安全字符；不要求整课所有课次具备单课文件名所需的日期/时间。旧单课命名校验不变。
- 生产路径每次读取/写完一张 JPEG 后再读下一张，保留原字节和背压；仅允许 O(页数+课次数) 元数据，不构造完整课程 Blob 或中间 PDF。读写失败停止后续读取，删除不完整缓存并恢复 busy。

主入口 `course-pdf` 按当前整理课次的课程；批量入口 `batch-course-pdf` 按批量列表课程。两者不能串域，批量课次的勾选或图库选择不改变整课范围。两种整课格式都等待 `namingSave`、`lessonSave`，再解析缺省课程键、快照标题和页序；显式 null 不回退当前课次。

## 工作台布局与可发现性

采用系统字体、暖白/浅灰表面、深色文字和现有 Logo 对应的酒红强调色；层次靠分组、留白、字重和明确标签。只有浮动工具层可用适度透明，不把每个按钮做成玻璃卡片，不添加装饰性大标题或动态背景。

- 顶部保留项目标识、当前整理课次与简短任务状态，建立清楚的来源 → 提取 → 整理/导出引导。导航只打开/定位对应设置，不擅自启动提取或下载。
- 左侧保留本机课次与来源/提取/导出三个检查器页签，使用清楚标签。选中来源旁显示完整名称和轨道提示；预检可用不等于 PPT 机位正确，不自动猜选轨道。
- 批量课次从窄视频设置栏移至工作区宽度的常驻折叠区域：关闭时仍有“批量课次”与数量入口，展开有读取、选择、开始、逐节状态和整课导出。保留识别课程列表后自动展开的行为，恢复任务也应有明确入口；不能说它过去始终隐藏。
- 预览下把“确认画面/裁剪”和“开始/继续提取、停止”分为主要操作；保存当前页、重扫、裁剪复用、缓存维护有各自次级分组。运行期间停止操作保持可见、可用。展开批量或可用高度受限时，以这一运行约束优先，允许把同一个现有停止控件或其操作行锚定在可见区域；不复制控件、不改变取消与保留结果逻辑，也不靠关闭批量面板或测试预先滚动来回避展开状态。
- 本节 PDF / 图片包、所选导出、页数/选择范围、文件名预览和“导出设置”入口集中在结果区附近；单个控件只保留一份 DOM，不复制 ID。当前课程合并 PDF / 分课 ZIP 的范围注明课程名称；批量区域注明其列表课程，保留不同处理器语义。
- 截图保持图像为主、选择状态明确、时间可回看，提示拖动调序和 Shift 连选。原有拖动调序没有键盘等价路径，本轮不扩展调序功能，也不宣称完整键盘调序。
- 桌面预览和图库并排且滚动有界；在 1280×800、1440×900、1920×1080 不发生文档横向溢出。窄窗口重排，390px 允许文档纵向滚动但不能横向溢出；图库仍用有界 `#pages` 滚动根。支持文字放大、系统深色、强对比；不修改截图颜色。

## 动效与可访问性

新增专用 `motion.js` 作为小型 UI 反馈层，向 `window.PPTMotion` 暴露 `reveal(element, {x = 0, y = 6, duration = 180} = {})`、`cancel(element)`、`cancelAll()`，均为同步 void；业务处理器不 await 动画。具体可由共享 reveal 完成，不为每种组件增加一套框架。

- 已启用按钮 pointer-down 即有轻压/色阶反馈，约 80–120ms；禁用按钮不伪造响应。
- 页签立即更新 aria-selected、tabIndex、hidden 与焦点，再给方向指示/短淡入。details 展开、框选成功提示、预览/dialog 入场使用约 140–200ms 局部 transform/opacity。
- 同一元素重复触发时，从当前呈现值继续并取消旧动画；不等待 transitionend、不增加 animationBusy、不延迟授权点击、保存完成或缺字段聚焦。
- 卡片只对少量可见增量反馈，任一批最多 12 张；恢复 1000 页不全量 stagger，不重建卡片，不逐帧测量全部卡片，不自动滚到底。删除成功即释放 URL，不为退出动画保留图片。
- `prefers-reduced-motion` 在 CSS 和 JS 同时响应，并在偏好变化时取消在途动画；换为短淡入或立即状态变化。透明和强对比均有实色高对比回退。
- 原生 dialog 的 showModal、Esc、close、焦点恢复即时生效；只保留一张当前原图，revision/异步加载保护不变。裁剪 Pointer Events 和键盘区域操作不变。
- 保留每课 1000 页、缩略图读取并发 ≤2、IntersectionObserver root=#pages / rootMargin=200px、离开范围释放 URL、节点复用与 scrollTop；动画不进入数据模型或保存任务。

## 验证与交付

基线 Node v26.13.0：207 单元测试、17 打包测试通过（33 成员）。浏览器仅使用现有隔离测试配置与 localhost 合成素材；不登录真实课程或上传资料。

PDF 验证递归 Unicode 目录与对象链接、奇数课次边界、目的地、逐图读取/失败、异步命名保存和两个课程域。UI 验证快速切换可中断、键盘/焦点、减少动态效果、不同宽度与深色截图，并保持原筛图、批量、缓存与失败回滚覆盖。每任务独立审查规格和质量，末尾整体审查。

版本统一 3.1.2。新增 motion.js 后安装包从 33 到 34 个成员；只更新当前清单与断言，保留历史验证事实和旧包。最终构建并核对本地 ZIP 成员、版本、CRC、源字节和 SHA-256，不触碰已发布 3.1.1。远端推送/合并/发布在结果可审查后按有效授权处理。
