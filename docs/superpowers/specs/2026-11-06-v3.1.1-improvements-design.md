# 3.1.1 提取、复核与课次管理改进

用户要求修复前一轮走查列出的全部问题，采用子代理实现和独立审查，并将版本号改为 3.1.1。用户随后要求“开始操作”，因此直接执行；下列细节是实现方选择，并非逐项向用户征求的决定。

## 目标与边界

覆盖提取准确性、筛图复核、课次管理与导出四组问题。保持现有原生 JavaScript / HTML / CSS、Manifest V3、IndexedDB 与 OPFS 架构，不引入运行时依赖或云服务。界面沿用现有控件、弹窗和配色。

- 最终扩展版本为 `3.1.1`，最低 Chrome `114`，测试要求 Node.js `>=20`。
- 每课次仍最多 `1000` 页，原图与缩略图按需读取，PDF / ZIP 保持逐图流式写入。
- 保留旧课次、截图、裁剪、采样设置和扫描断点；读取旧记录时兼容缺少新字段的情况。
- 忽略区只参与画面比较，不修改截图或导出图像。
- 所有新操作遵循忙碌状态、使用约定、持久化失败处理和键盘可访问性。
- 自动化验证只使用本地合成素材和隔离浏览器配置，不访问真实课程、账号或日常浏览器资料。
- 本轮仅本地实现、提交、测试和打包；不推送、不合并共享分支、不创建远程发布。

## 方案比较

1. **现有模块内补齐能力（采用）**：复用扫描器、课次存储和导出器，逐项添加必要入口及状态；改动可以分别测试和审查。代价是主控制器仍较大，需要保持操作边界清楚。
2. **重写工作台并引入框架**：能重新划分组件，但增加依赖、迁移和数据风险，对这些明确问题收益不够。
3. **接入云端识别 / OCR**：可能进一步识别课件语义，但新增上传、账号和费用，超出本轮需求。

## 1. 提取准确性与去重

- 新课次默认选择 `0.5` 秒精细采样。保留已有 `2` 秒、`8` 秒模式和旧课次明确保存的模式，并提示粗采样可能漏掉短暂翻页。以 A→B→A 合成序列验证默认模式捕获中间稳定画面；不承诺捕获持续时间短于采样间隔或稳定确认窗口的任意画面。
- 提供一个可绘制、可清除的矩形忽略区，用于画中画、角标等。矩形使用归一化坐标，限定在所截 PPT 区域内。比较时跳过该区域，差异比例以剩余像素数计算；不能将整个有效区域全部忽略。
- 原始签名与原图保持不变。扫描相邻帧、确认帧、全局去重、实时截取和相似页候选判断必须使用同一忽略规则。旧截图若裁剪几何与当前区域不一致，不误用区域坐标；采取保守比较。
- 忽略区按课次保存，切换课次与刷新恢复；调整裁剪后清除旧忽略区并提示重新设置；忽略区变化会使旧断点不能直接续扫。
- 去重签名只在正在进行的扫描/实时任务中缓存，限制在当前课次的 `1000` 页以内，不保留 JPEG / 缩略图，不挂在全局课次库上。成功存图后才加入缓存；任务结束、失败、取消或换课次释放。重复候选复用已经读过的签名，数据库失败不能被当成“不重复”。

## 2. 筛图与复核

- “清理相似页”改为候选对比弹窗。依旧仅比较同时间线、时间递增且尺寸相同的相邻页。每对显示两张图、页序和时间；用户可选择保留前页、保留后页或两页都保留，默认两页都保留，未经确认不删除。
- 重叠候选按顺序评估当前保留页，避免 A/B、B/C 的矛盾选择导致两张候选都被删除。所有已确认删除在一次现有删除事务中提交，可一次撤销；取消整个弹窗不改数据。对比图按当前候选加载并及时释放 URL。
- 支持 Shift+点击复选框选择/取消连续范围，以当前显示顺序和最近一次普通点击为锚点；换课次、清空和无效锚点不得跨课次选中。
- 大图预览增加可见的选中/取消入口，键盘 `S` 切换选中、`V` 回看；保持原有箭头翻页、Delete、Esc 和输入控件按键行为。
- 批量列表每行增加“查看截图”，直接切到该课次的截图与待复核区间；无需加载视频即可整理，忙碌时禁用。
- 待复核区间增加“已确认”，只移除该区间并持久化；不要求加载视频；写入失败时保持原记录及可重试状态。

## 3. 课次库与批量裁剪

- 本机课次处提供管理入口，显示每节的页数和图片/缩略图/签名合计体积，明确是图片数据大小估算，不伪称浏览器完整磁盘占用。旧记录可按需逐条读取体积，避免一次加载全库图片。
- 支持删除单个课次或当前整门课的历史。操作在产品内确认具体课次/课程、页数以及不可撤销；不自动替用户清理数据。
- 删除原子地更新 pages、assets、lesson 元数据、activeLesson 和关联批量记录；不留下可重新恢复被删课次的旧批量状态；不影响别的课次/课程。存储失败保留原视图与数据。删除正在打开课次时释放视频、缩略图、预览和撤销状态，并切换到剩余课次或空状态。
- 在已确认裁剪的 0 路课次提供“将当前裁剪应用到本课其余 0 路课次”。明确这是固定机位下的复用，先产品内确认，再把同课程未完成 0 路任务加入可批量队列。
- 复用保存所选通道身份、归一化裁剪与来源宽高比；实际加载每节后校验宽高比（允许相对误差不超过 `1%`）。通道变更、宽高比不匹配或无效裁剪则回到需人工框选状态，不能默默使用完整画面。已完成课次和其他课程不覆盖。
- 保留逐节调整入口，批量任务停止、失败、重新发现课次和刷新后仍准确反映裁剪确认状态。

## 4. 导出

- 保持右上角“全部保留页”的原有含义，增加独立“导出所选 PDF / 图片包”入口；不让已有勾选悄悄改变全部导出。所选页按当前显示顺序输出，零选择禁用，文件名加入 `-selected` 区分。
- PDF 设置增加“标注视频时间”和“生成页码书签”，默认均关闭以保持旧导出默认结果。单页 PDF 的时间在图片外页脚显示；讲义 PDF 在每张幻灯片页码附近显示。不覆盖图片，不写伪造时间。
- 书签使用 ASCII 页码与有效 `HH:MM:SS` 时间，指向具体 PDF 页/讲义对应位置。缺少或非有限时间时只有页码。中文课名仍用于文件名，不新增字体依赖。
- `makePDF`、`writePDF` 与 `writeCourseZIP` 接受并一致传递时间/书签选项；未开启选项时保持现有 PDF 字节兼容测试。图片包不受 PDF 设置影响。
- 批量面板新增“下载本课 PDF 包”，复用整课导出实现，但课程范围来自该批量列表，不能误用当前打开的另一门课；继续说明空课次与未完成课次情况。

## 验证与交付

每项实现补充覆盖实际用户行为的回归用例，由独立子代理读取对应 diff 进行规格及质量审查。最终运行 Node 单元、打包与受影响浏览器套件；针对 PDF 验证目录对象、链接目标、时间标注、顺序和流式背压；针对课次管理验证跨课隔离和写入失败。

统一 manifest、包配置/锁文件、界面、当前版本测试夹具与 README 到 3.1.1。历史设计文档中的旧版本保留。生成本地安装包与简明变更说明，交付实际测试结果、未验证范围和实现选择的代价。

## 收尾追加：命名顺序与 README 横幅

- 整分支终审发现：裁剪复用在命名保存尚未提交时，可能用旧课次快照覆盖成功的新命名。复用确认必须先等待 namingSave 和 lessonSave，再按最新状态计算目标和构造快照，保持课次与批量记录原子提交、提交后更新界面。用真实 IndexedDB 的延迟提交与实际复用对话框验证名称、日期、时间、手工命名标记经重载仍保留，且其他课次/批次不变；现有异步写失败回滚断言保留。
- 用户在收尾阶段追加了明确的小改：README 开头改用 SVG 横幅，左侧 Logo、右侧名称，完成后移除最初的标题。沿用现有 `XJTU PPT Capture Extension` 名称和高清 Logo，不改品牌内容。原先独立 Logo 与一级标题一起替换成一个横幅，原有介绍、提示、版本和其余内容保留。
- 由我选择的视觉方案：米白底、红棕色文字、少量课件页细线背景；完整名称用 SVG 文字，保留左图右文的横向构图。参考 viewBox 1200×300，在 README 常见桌面宽度与窄屏下不裁切。颜色、字体和装饰是实现选择，不冒称用户逐项确认。
- 采用自包含 SVG：直接嵌入现有 `icons/logo-1024.png` 的原始 PNG 数据，保留高清细节，不依赖外部图片、字体或脚本；不用 GitHub 会过滤的 README 内联 SVG。图中文字提供标题/描述，README 图片提供项目名替代文本。相较重新绘制 Logo，它保持现有品牌；代价是 SVG 内含栅格 Logo 数据，体积增加，名称和背景仍为矢量。
- 新增 `icons/readme-banner.svg` 并加入发布白名单；包含 README 的本地安装包也必须包含它，所以当前成员数从 32 变为 33。只更新当前打包期望和说明，历史已执行的 32 成员 fixture 证据不改写。静态检查自包含性/嵌入图像一致性，使用隔离本地浏览器实际渲染桌面与窄屏预览；不增加低价值的布局快照测试或运行时依赖。
- 此追加与终审唯一 I1 合并为一次限定的最终实现波次，由新实现者完成，新审查者定向复核完整增量（含新增横幅与打包边界）。原有四组改进及本地交付边界保持有效。
