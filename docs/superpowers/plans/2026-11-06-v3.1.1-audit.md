## 已确认事实与 Ruling

- 用户要求修复前一轮全部问题、使用 subagent-driven-development、将版本设为 3.1.1，随后要求开始操作。Ruling：直接执行常规实现选择，不再重复征询设计批准；本记录不代表用户逐项认可技术细节。
- 采用现有原生模块，零新增运行时依赖。每次只允许一个实现者修改文件，每任务由新审查者复核规格与质量。
- 前四组实施时可用子代理模型为 `magpie-responses/codex/gpt-6-astra`，任务用 high、独立审查按复杂度使用 high/xhigh。续跑时模型目录已变为 `magpie-responses/codex/gpt-6.1-sol`（high/xhigh/max）；后续任务显式选择该模型，最终审查使用最高推理等级。未发现更便宜的可选模型。
- `using-git-worktrees` 技能不可用，使用标准 git worktree 创建隔离分支。规则查询工具未注册，未将普通记忆搜索伪称规则查询；已读取本地约束，经验搜索无相关结果。
- Ruling：默认 0.5 秒采样修复常见 A→B→A 漏页，但保留显式保存的 2/8 秒设置；有限采样无法保证发现任意短暂画面。
- Ruling：任务期最多缓存当前课次 1000 个原始 RGBA 签名，有效载荷上界 82,944,000 B（79.10 MiB），不缓存图片 Blob；这不是进程整体内存上界。任务结束释放。
- Ruling：旧页没有裁剪元数据时保守地使用无忽略区比较，不从当前课次裁剪反推旧页；新页保存签名对应的裁剪快照。
- Ruling：产品内删除课次/课程和复用裁剪需要产品确认，不等于开发阶段需再向用户确认。本轮实现这些入口，不对用户真实数据执行清理。
- Ruling：PDF 时间、目录默认关闭；选中页导出使用独立按钮，既有全部导出始终导出所有保留页。用户需自行开启可选导航。
- Ruling：仅提供一个忽略矩形，以最小改动覆盖画中画；多个分散遮挡可能需要更大的忽略范围，减少实际参与比较的内容。
- Ruling：只强制加入本轮编写的设计、计划、审计及任务报告，保留本地忽略规则；代价是隔离分支包含这些可恢复的过程文档，不包含其他原本被忽略的文件。
