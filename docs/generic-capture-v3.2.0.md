# 通用视频提取第一版（3.2.0）

分支：`Widly-applicable-capture`。完成日期：2026-11-11。

## 恢复的任务

原聊天“我们现在这个PPT截取网站，都更新哪些功能了”在创建分支后中断。聊天记录中，实现请求及随后两次重试都以 `{"detail":"Bad Request"}` 失败，状态为 `systemError`；没有更详细的错误信息。恢复时分支已存在，工作区干净，没有已写入的实现需要合并。

## 行为

- 在 HTTP(S) 视频页点击扩展后，保留当前来源标签页，并利用 `activeTab` 注入采集器；不增加默认所有网站访问权限。
- 工具页列出浏览器允许读取的网页标签页；从 DOM、已加载资源、注入后的 fetch/XHR JSON 及可访问 iframe 收集视频。来源页与媒体域名分开按需授权。
- 可读取的 MP4、WebM 和未加密点播 HLS 继续使用已有加载、预览、裁剪、扫描、整理和导出流程。同页多个视频由用户逐个加载确认。
- 普通网页以页面标题作为默认课程名，缺少日期、时间时可直接按标题导出。文件名预览与实际导出使用同一规则。
- 思源学堂的接口探测、目录批量与 0/2 路机位提示仅在其站点使用。普通网站不会因为 URL 中存在 `courseId` 或相似路径而请求思源接口。
- 切换来源、导航和关闭来源时清理视频候选，已存截图仍按来源页和视频身份保存。无法读取时提示重新点击扩展、授权或使用实时共享画面。
- 明确拒绝加密 HLS 和直播快速扫描；DASH 沿用原有不支持提示。

测试依赖使用本机捆绑 Node 模块，浏览器为隔离配置的 Edge 157.0.4341.46，不访问用户日常浏览器配置或学校账户。沙箱内浏览器启动崩溃、本地 HTTP 预检连接失败及目录 symlink 创建被拒绝；在获准的沙箱外测试中均完成。新增一项 VM 数组断言曾因跨 realm 原型不同失败，已用原生 `Array.from` 转换后通过。

## 边界

上述两个域名是本地夹具，未实测两个真实第三方教学站点。无头测试预先授予本地域名，并调用已注册的工具栏处理函数；真实工具栏点击带来的临时 `activeTab` 授权及拒绝授权对话框未做原生 UI 验证。拒绝授权的分支用返回 false 的权限 API 替身验证。可访问 iframe 不代表首版能自动授权任意跨域播放器。

仅暴露 blob 的播放器、加密媒体、登录失效、复杂跨域内嵌和未暴露原始 URL 的站点仍可能无法快速提取，可使用已有实时共享画面或本地文件。未新增第三方平台整课适配器，未发布远程版本，未合并主分支。
