# 本地验证

测试仅使用隔离浏览器配置和本地生成的录像，课程域名的测试页面由测试代码拦截并提供，不向学校发送请求，也不读取日常浏览器配置。

`npm test` 不需要第三方依赖，验证视频地址解析、首尾采样、噪声处理、并发记录、课程切换缓存隔离，以及课程名称 / 时间解析、实际网页的日期+星期+开始时间格式、时区、非法日期、文件名字符、JSON ID 过滤与元数据来源校验。

`node tests/bridge.cjs` 使用隔离浏览器验证继承来源的 srcdoc、来源为 null 的沙箱 srcdoc 和沙箱 URL 页面。修复前会复现 Invalid target origin 'null' 错误；修复后验证视频地址消息正常往返、定时采集不报错，以及其他窗口的伪造消息被拒绝。

`node tests/integration.cjs` 需要 Node.js、FFmpeg、Poppler 的 pdftoppm，以及 playwright、sharp、pdf-lib。在仓库目录运行 `npm install` 安装开发测试依赖。Windows 默认使用已安装的 Edge；其他环境需先运行 `npx playwright install chromium`。通过环境变量 `PPT_TEST_NODE_MODULES` 指定已有依赖目录，`PPT_TEST_BROWSER` 指定支持加载解压扩展的 Edge/Chromium 可执行文件。测试仅为隔离扩展副本预先授予本地视频服务器的访问权，生产 manifest 保持视频域名按需授权。

集成测试验证：

- 从 JSON 接口响应发现视频地址，即使该地址未出现在 video 元素中；不自动选择视频，由使用者手动筛选。
- 截取完成后没有自动下载事件，显示页面筛选提示；删除页面后手动下载，仅导出保留的页面。
- PDF 实际下载名符合课程名称-上课日期-开始时间格式；纯 JSON 元数据和网页文字格式均验证。
- 旧版数据库升级不丢截图；缺少课程信息不下载；命名自动恢复，手动校正写入下载名并持久化；切换课程不误改已有截图名称。
- 不提供 CORS 响应头的 MP4 能通过插件下载、本地 Blob 解码并截页，课程 Referer 随请求正确携带。
- 密集采样得到 4 个不同页面，并去除重复回看页面；稀疏模式对短暂页面的漏截边界有明确测试。
- HLS 按分片跳转得到相同的 4 张幻灯片；本地视频导入正常。
- “释放视频缓存”在无视频 / 截取中禁用；MP4、本地视频的 Blob URL 被撤销，HLS 被卸载；截图、自动和手动命名保持不变，释放后仍能导出 PDF，重新加载视频后可再次提取。
- 截图在工具页重开后恢复，停止扫描保留已提交截图，框选排除预览留白，HTTP 错误不清除结果。
- 实际生成的 PDF 用独立解析器读取页数和页面尺寸，渲染筛选后保留的全部页面并与输入画面逐像素比较，验证内容、顺序和比例。

测试中间文件放在 `.test-output/`；不包含在发布包中。合成录像不能替代目标课程登录后的实测，也不能据此推断真实长课程的耗时。

`npm run test:release` 验证发布包运行文件白名单、版本一致、根目录只保留固定名最新版、旧版包原样归档、历史重名不覆盖、构建失败不修改最新版。使用 `.test-output/` 隔离目录，不修改真实发布包。
